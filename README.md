Entering a new order
- On the home screen, click the "New Order" button.
- A yellow window will open, complete all fields and click "Save Order".
    - Failure to enter all fields will result in an error and the order will not save until everything is filled in.
    - Failure to use the SR-000XX format for the order ID will result in an error.
    - If the order ID already exists in the excel file, it will result in an error. 
- When the order saves successfully, a success message will appear. 
- Clicking on "Home Screen" will return the user to the first page. 
- Clicking on "Exit Application" will end the program.
- Clicking on "Recent orders" will open a red window that displays the ten most recently added rows.

Viewing recent orders
- Users can access the recent orders screen in two ways:
    - Via the "Recent Orders" button on the home screen
    - Via the "Recent Orders" button on the new order screen
- The Recent Orders Screen displays the ten most recent rows added to the excel file. It does not   display the ten most recent dates orders were submitted. 
    - That is because this is purely to track spending, analysts may enter orders into the track on the day that they submit them or at a later date. 
- Users may delete an order by selecting it in the view pane and clicking on "Remove Selected"
    - Users may only delete one line at a time.
    - A warning appears, ensuring the user confirms they want to delete the order.
- Users may update an order by selecting "Update Selected".
- Users may return to the new order screen by selecting "Add Another Order".
- Users may return to the home screen by selecting "Home".
- Users may exit the application by selecting "Exit"

Updating an order
- All fields may be updated except for the Order ID
- User must add their name to the "Modified By" field
- To save changes click on the save button. 
- The excel will update and so will the viewing pane. 
- There will be two new columns, modified by and date modified.
